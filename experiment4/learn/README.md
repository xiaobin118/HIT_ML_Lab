# 从零重写实验四：分步学习路线

这不是"再读一遍报告"，而是把已经完成的 `code/` 拆成 7 个可以自己动手的小步骤。
每一步你只写少量函数，写完立刻有自检脚本告诉你对不对，然后我们再讨论。

> **重要规则：不要打开 `code/` 里的成品实现。**
> 那里的代码是给你最后对照用的。先自己写，卡住 20 分钟以上再来问；
> 写完一步后可以对照，看看两种写法有什么不同。

## 怎么上课

1. 读当前步骤的讲义（`docs/` 下）。
2. 在 `practice/` 里只修改标了 `TODO` 的地方。
3. 运行自检脚本，例如 `python step01_linear.py`。
4. 把**运行输出**和**你写的函数代码**发给我，并写一句"哪里最别扭/最不确定"。
5. 我 review 后再发下一步的讲义和骨架。

代码里每个函数都有类型标注；`Array`、`Ws`、`bs`、`fan_in`、`he`/`xavier`
这些名字的含义见 [名词与类型速查](docs/00b_名词与类型速查.md)。

每一步预计 1～2 小时。不要跳步：第 3 步的反向传播依赖第 2 步的前向形状，第 5 步的实验依赖第 4 步的训练循环。

## 你可能会问

**Q：我已经看过 `code/mlp.py` 了，还有必要重写吗？**
A：看懂和写出来是两件事。反向传播里"维度对不上""转置写反""少乘激活导数"这三类错误，
只有自己写到报错、再用数值梯度查出来，才会真正记住。

**Q：可以直接抄成品吗？**
A：可以，但那就只是练打字。建议先写一版能跑的，再对照成品改一版，最后合上所有代码，
从空白文件重写 `loss_and_grads`。第三遍才是真正学会的时候。

**Q：卡住了怎么办？**
A：先做三件事：打印每个数组的 `shape`；用 2 个样本、3 个特征的小例子手算一遍；
把自检的哪一项 FAIL 和完整报错发给我。不要直接问"怎么写"，先告诉我"我预期是什么、实际是什么"。
