# 从零重写实验五：用 PyTorch 写 CNN

这不是"再读一遍报告"，而是把已经完成的 `code/` 拆成 9 个可以自己动手的小步骤。
每一步你只写少量函数，写完立刻运行自检脚本，结果对/错马上知道；通过后我们再进入下一步。

> **重要规则：在做到对应步骤之前，不要打开 `code/` 和 `exp5_report/` 里的成品实现。**
> 成品代码是给你最后对照用的。先自己写；卡住 20 分钟以上再来问。

## 怎么上课

1. 读当前步骤的讲义（`docs/` 下）。
2. 在 `practice/` 里只修改标了 `TODO` 的地方。
3. 运行自检脚本，例如 `python step00_pytorch_warmup.py`。
4. 把**运行输出** + **你写的 TODO 代码** + 一句"哪里最别扭/最不确定"发给我。
5. 我 review 之后，再发下一步的讲义和骨架。

每一步预计 1～2 小时。**不要跳步**：第 2 步的 LeNet-5 依赖第 1 步对卷积输出尺寸的理解；
第 4 步的训练循环依赖第 2、3 步；第 6 步以后的对照实验依赖第 4、5 步的训练系统。

## 和实验四的区别

实验四（MLP）要求你**手写反向传播**，因为当时要理解"梯度是怎么传的"。
这次用 PyTorch，`loss.backward()` 会自动算梯度——**框架把反向传播接管了，你只需要写前向结构 + 训练循环 + 评估**。
所以这次的学习重点变成：

1. 张量和设备（数据、模型必须在同一块设备上）——第 0 步；
2. 卷积、池化、通道、感受野这些**结构概念**——第 1、2 步；
3. 把"数据 → 训练 → 验证 → 实验对照 → 误差分析"整条流水线写出来——第 3～8 步；
4. 会设计**控制变量实验**，并用图表和指标解释结果——第 6～8 步。

实验四里你已经证明过自己懂梯度下降和交叉熵，这次不再重复推导，而是把精力放在 CNN 的特有概念和工程实践上。

## 你可能会问

**Q：我已经看过 `code/models.py` 了，还有必要重写吗？**
A：看懂和写出来是两件事。形状对不上、`dim` 写错、忘了 `zero_grad`、数据没搬到 GPU——
这些错误只有自己写到报错、再一条条查出来，才会真正记住。

**Q：可以直接抄成品吗？**
A：可以，但那就只是练打字。建议先写一版能跑的，再对照成品改一版，最后合上所有代码，
从空白文件重写一遍。第三遍才是真正学会的时候。

**Q：卡住了怎么办？**
A：先做三件事：打印每个张量的 `shape` / `dtype` / `device`；用 2 个样本、3 个通道的小例子手算一遍；
把自检的哪一项 FAIL 和完整报错发给我。不要直接问"怎么写"，先告诉我"我预期是什么、实际是什么"。

**Q：我想先看成品、只求能讲清代码，不重写行不行？**
A：行，但告诉我一声，我换一条路线：按"模块拆解 + 逐段讲解 + 小测"的方式带你读现成代码，
而不是让你从零写。默认按"从零写"路线走。
